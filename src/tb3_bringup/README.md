# `tb3_bringup`

Launch files, Gazebo scenes and models, robot setup, and RViz for LocateAnything.
The velocity relay gives the simulator one drive-command writer with a timeout.

- Start a scene with `locateanything_demo.launch.py`; see the [main README](../../README.md#run-locateanything).
- [Launch guide](launch/README.md): simulator, SLAM/Nav2, and perception/navigation backend.
- [Worlds](worlds/), [models](models/), and [RViz configuration](rviz/semantic_nav.rviz).
- Third-party model attribution is in [NOTICE](../../NOTICE).
